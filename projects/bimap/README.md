# 📦 sandbox-bimap

Двунаправленный словарь (`BiMap`), обеспечивающий взаимно-однозначное соответствие между уникальными ключами и уникальными значениями на базе стандарта C++20. Проект оформлен в виде статической библиотеки и позволяет осуществлять эффективный поиск как значения по ключу, так и ключа по значению за $O(1)$.

## 🛠 Технологический стек & Архитектура

* **Стандарт:** C++20
* **Система сборки:** CMake + CTest
* **Тестирование:** Google Test (GTest)
* **Специфика:** * **Идиома Pimpl (Pointer to Implementation):** скрывает внутреннюю структуру контейнера и детали реализации (хеш-таблицы, дек) от пользователя, ускоряя компиляцию зависимых модулей.
    * **Управление памятью & RAII:** использование `std::unique_ptr` для контроля жизненного цикла реализации библиотеки.
    * **Move-семантика:** полная поддержка перемещения объектов для исключения лишних аллокаций памяти.
    * **Strict Exception Safety:** метод добавления элементов спроектирован с учетом строгой гарантии безопасности исключений.

## 🚀 Сборка и запуск

Сборка проекта выполняется стандартными командами:

```bash
cmake -S . -B build -DBUILD_TESTS=ON
cmake --build build
ctest --test-dir build --output-on-failure

```
