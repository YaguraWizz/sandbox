# [Название проекта vector.v2] 🚀

> Динамический массив (вектор) с низкоуровневым управлением памятью (RAII + Placement New).

---

## 📝 Описание

Данный проект является частью учебной песочницы и представляет собой продвинутую реализацию кастомного контейнера `Vector`. В отличие от первой версии, здесь разделены этапы выделения памяти и конструирования объектов. Выполнен в рамках обучения в Yandex Practicum.

### Особенности реализации:
* **Стандарт:** C++20.
* **Управление сырой памятью:** Вместо стандартного выделения через `new[]` используется класс `RawMemory`. Память выделяется без автоматического вызова дефолтных конструкторов элементов.
* **Placement New:** Элементы создаются непосредственно в выделенном буфере памяти по запросу с использованием `std::construct_at`, а уничтожаются через `std::destroy_at` / `std::destroy_n`.
* **Идеальное перенаправление (Perfect Forwarding):** Реализован метод `Emplace`, позволяющий конструировать элементы прямо внутри вектора без лишнего копирования или перемещения аргументов.
* **Строгие гарантии исключений:** Операции реаллокации и вставки защищены блоками `try-catch` для предотвращения утечек памяти при возникновении исключений в конструкторах элементов.
* **Форматирование:** Единообразный стиль кода с помощью настроенного `.clang-format`.

## 🚀 Сборка и запуск
Сборка проекта выполняется стандартными командами CMake.

```bash
cmake -S . -B build -DBUILD_TESTS=ON
cmake --build build
ctest --test-dir build --output-on-failure
```
