## 📝 Описание

Данный проект является частью учебной песочницы и представляет собой базовую реализацию кастомного контейнера `SimpleVector`. Выполнен в рамках обучения в Yandex Practicum.

### Особенности реализации:
* **Стандарт:** C++20.
* **Управление памятью:** Использование кастомного RAII-указателя `ArrayPtr`.
* **Оптимизации:** Поддержка move-семантики для перемещения тяжёлых или неперемещаемых объектов.
* **Форматирование:** Единообразный стиль кода с помощью настроенного `.clang-format`.

---

## 🚀 Сборка и запуск
Сборка проекта выполняется стандартными командами CMake.

```bash
cmake -S . -B build -DBUILD_TESTS=ON
cmake --build build
ctest --test-dir build --output-on-failure
```
