# **Sandbox Combinatorics 🧮**

Учебная библиотека на C++20 для работы с комбинаторными объектами и длинной арифметикой.

## **📝 Описание**

Данный проект разрабатывался в рамках университетской практики (2-3 курс). Он представляет собой библиотеку заголовочных файлов (header-only) для работы с базовыми конфигурациями комбинаторики.

Код писался для закрепления теории на практике: возможно, алгоритмы не являются эталоном производительности в production-среде, но они работают, корректно выполняют математические вычисления и покрыты юнит-тестами.

### **Ключевые возможности:**

* **Комбинаторные выборки:** Алгоритмы для генерации Сочетаний (Combinations) и Размещений (Arrangements) элементов любых типов.  
* **Перестановки (Permutations):** Работа с перестановками, включая нахождение конкретной перестановки по её лексикографическому номеру (индексу) и получение индекса по самой перестановке.  
* **Факториальная система счисления (Index):** Вспомогательный класс для конвертации чисел в факториальный вид, что необходимо для быстрого индексирования перестановок.  
* **Длинная арифметика (UnsignedInteger):** Кастомная реализация для работы с очень большими беззнаковыми целыми числами (сложение, вычитание, умножение, деление), так как значения факториалов быстро выходят за лимиты стандартного unsigned long long.

## **🚀 Сборка и запуск тестов**

Для сборки проекта и прогона юнит-тестов (используется фреймворк Google Test) применяются стандартные команды CMake:

```bash
cmake -S . -B build -DBUILD_TESTS=ON
cmake --build build
ctest --test-dir build --output-on-failure
```
