# HPC

Экспериментальная площадка для задач высокопроизводительных и параллельных вычислений.

Подпроект предназначен для исследования алгоритмов, методов распараллеливания и сравнения различных технологий выполнения вычислительно сложных задач.

На данный момент репозиторий находится на этапе формирования структуры. Реализации будут добавляться постепенно по мере появления времени и практической необходимости.

## Основные направления

* линейная алгебра;
* теория графов;
* вычислительная математика;
* вычислительная геометрия;
* обработка сигналов;
* обработка изображений;
* криптография;
* параллельные и распределённые вычисления.

## Подход к организации

Структура проекта ориентирована на предметные области и алгоритмы, а не на конкретные учебные курсы или дисциплины.

Для отдельных задач могут присутствовать несколько реализаций:

* последовательная;
* OpenMP;
* MPI;
* CUDA;
* другие технологии и экспериментальные варианты.

Это позволяет сравнивать производительность, масштабируемость и особенности различных подходов в рамках одной задачи.

## Статус

Проект является долгосрочным набором экспериментов и учебно-исследовательских реализаций.
