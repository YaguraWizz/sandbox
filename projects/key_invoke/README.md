# 📦 key_invoke

Легковесная C++ библиотека заголовков для автоматического диспатчинга аргументов и вызова функций/методов на основе ключей из произвольных контейнеров (например, JSON). Она избавляет от ручной распаковки данных, автоматически сопоставляя типы параметров функции со структурой в контейнере.

## 🛠 Технологический стек & Архитектура

* **Стандарт:** C++17 / C++20 (поддерживает оба режима, для C++20 доступен расширенный компиляционный синтаксис с именованными типами `Value`)
* 
**Система сборки:** CMake + CTest 


* 
**Тестирование:** Google Test (GTest) 


* **Специфика:** Compile-time рефлексия сигнатур через метапрограммирование (`FunctionTraits`), рекурсивное построение кортежа аргументов на этапе компиляции, строгая валидация количества параметров через `static_assert` и расширение через ADL-точки (`extract_value`).

---

## 🚀 Сборка и запуск

Сборка проекта выполняется стандартными командами:

```bash
cmake -S . -B build -DBUILD_TESTS=ON
cmake --build build
ctest --test-dir build --output-on-failure

```
