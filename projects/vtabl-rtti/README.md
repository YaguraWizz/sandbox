# 📦 Sandbox: Ручная симуляция VTable и RTTI в C++20

Экспериментальный проект, в котором реализован механизм **динамического полиморфизма и виртуального наследования вручную** (без использования стандартных ключевых слов `virtual`, `override` и `dynamic_cast`). 

Проект наглядно демонстрирует, как компилятор C++ разворачивает таблицы виртуальных функций (`vtable`), организует смещение указателей при наследовании и обеспечивает безопасное разрушение объектов через явные замыкания функций.

## 🛠 Технологический стек & Архитектура

* **Стандарт:** C++20
* **Система сборки:** CMake + CTest
* **Тестирование:** Google Test (GTest)
* **Специфика реализации:**
  * **Ручные таблицы функций (`VTable`):** Структуры, хранящие сырые указатели на статические функции-переходники (`BasePrint`, `BaseDelete`, `BaseCopy`).
  * **Виртуальные деструкторы:** Механизм освобождения памяти `Delete()`, восстанавливающий исходный тип объекта через `reinterpret_cast`.
  * **Безопасность памяти (RTTI):** Шаблонный метод `verify` внутри `IdentityDocumentVTable`, проверяющий, что указатель на таблицу находится строго по нулевому смещению объекта (имитация макета класса в GCC/Clang).
  * **Глубокое копирование:** Реализация паттерна «Виртуальный конструктор копирования» на чистом C.
