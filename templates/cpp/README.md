# Односвязный список (SingleLinkedList) 🚀

> Кастомная реализация последовательного контейнера `SingleLinkedList` на языке C++20 с поддержкой STL-совместимых итераторов и строгой гарантией безопасности исключений.

---

## 📝 Описание

Данный проект является частью учебной песочницы и представляет собой продвинутую реализацию линейного односвязного списка (`SingleLinkedList`), разработанную в рамках изучения низкоуровневого управления памятью и устройства стандартных контейнеров STL. Выполнен в рамках обучения в Yandex Practicum.


Контейнер инкапсулирует владение динамической памятью, автоматически управляет временем жизни узлов и предоставляет интерфейс, максимально приближенный к `std::forward_list`.

### Ключевые фичи и характеристики:
* **STL-совместимые итераторы:** Реализован собственный `BasicIterator` (категория `std::forward_iterator_tag`), что позволяет использовать контейнер с диапазонами (`range-based for`) и стандартными алгоритмами из `<algorithm>` (например, `std::equal`, `std::lexicographical_compare`).
* **Строгая безопасность исключений (Strong Exception Safety):** Оператор присваивания и копирующие конструкторы реализованы по принципу *Copy-and-Swap*. Если в процессе копирования элементов или выделения памяти происходит сбой (например, `std::bad_alloc`), исходное состояние списка гарантированно остаётся неизменным.
* **Эффективное управление памятью:** Реализован метод `AppendFromRange` для линейного копирования диапазонов, а также эффективные атомарные операции вставки и удаления (`InsertAfter`, `EraseAfter`, `PopFront`).

## 🚀 Сборка и запуск
Сборка проекта выполняется стандартными командами CMake.

```bash
cmake -S . -B build -DBUILD_TESTS=ON
cmake --build build
ctest --test-dir build --output-on-failure
```
